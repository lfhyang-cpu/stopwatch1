# 🐾 어질리티 스탑워치

반려견 캐릭터가 어질리티 코스(허들·위브폴·타이어·터널·A-프레임)를 시간에 맞춰 도는 게임 느낌의 스탑워치입니다.

## 파일
- `agility-stopwatch.html` — 어질리티 스탑워치 (메인)
- `stopwatch.html` — 기본 스탑워치

## 사용법
HTML 파일을 브라우저로 열면 바로 실행됩니다(설치 불필요).

- `Space` 시작/정지 · `L` 랩 · `R` 리셋 (한글 입력 상태에서도 동작)
- 코스 1바퀴 시간: 15초 / 20초 / 30초 / 1분
- 강아지 이름·털색·귀 모양 꾸미기, 누적 바퀴로 칭호·액세서리 해금
- 랩 기록, 지난 기록, 결과 공유, 다크모드, 소리(기본 꺼짐)

## 점검
브라우저 콘솔에서 `agilitySelfTest()` 실행 시 자체 테스트 29개를 수행합니다.
